# 04. 发布分发计划

## 发布目标

本轮发布不追求“广撒网”，而是先完成三件事：

1. 建立 OPC-Studio 的清晰认知：一人公司的增长操作系统。
2. 吸引第一批 OPC 创始人提交项目或体验 AI 拆机器。
3. 让企业客户、投资人和生态伙伴知道这里正在沉淀一批 AI 原生小微团队。

## 发布节奏

### D-3：预热

主题：

> 一个人，也能是一家公司吗？

内容：

- 发起讨论：AI Agent 是否正在改变公司的最小单位？
- 发布社媒卡，但不完整介绍产品。
- 引导关注“OPC”概念。

推荐文案：

> 过去，一个人最多被叫自由职业者。现在，一个人 + 一组 AI Agent + 一个垂直场景，可能已经是一家公司。  
> 我准备把这种新组织形态系统性记录下来。

### D-1：产品预告

主题：

> 我在做 OPC-Studio

内容：

- 解释 OPC-Studio 的一句话定位。
- 展示主视觉海报。
- 预告 AI 拆机器。

推荐文案：

> 我在做 OPC-Studio，一个服务一人公司生态的 AI 原生增长操作系统。  
> 它会从展示、内容、拆解、连接和 Agent 工作流几个方向，帮助优秀 OPC 被市场看见。

### D-Day：正式发布

主题：

> 一个人，也能是一家公司：OPC-Studio 发布

内容组合：

- 长文：发布公告
- 图片：主视觉海报
- 短文：即刻 / 朋友圈版
- CTA：体验 AI 拆机器 / 提交 OPC 项目

### D+2：功能演示

主题：

> 用 AI 拆机器生成你的 OPC 项目卡

内容：

- 录制 1-2 分钟屏幕演示
- 展示输入项目说明到生成评级卡的过程
- 鼓励用户贴出自己的项目说明

### D+7：案例复盘

主题：

> 第一批 OPC 项目，我们看到了什么？

内容：

- 总结收到的项目类型
- 提炼共性：AI 如何进入工作流、创始人如何放大产能
- 预告 PitchRoom

## 渠道适配

### 朋友圈

目标：建立个人信任和第一批种子用户。

形式：

- 主视觉海报 + 300 字发布短文
- 评论区放链接或“想体验可以私我”

### 即刻

目标：获得独立开发者和 AI 产品圈反馈。

形式：

- 观点型开头
- 产品链接
- 诚恳征集 OPC 样本

### 小红书

目标：扩大“一个人公司”概念认知。

形式：

- 社媒卡做封面
- 标题用“一个人，也能是一家公司”
- 内容偏解释：什么是 OPC、适合谁、如何自测

### LinkedIn

目标：触达海外/跨境/投资人/生态伙伴。

形式：

- 英文短文
- 强调 One Person Company 和 AI-native organization
- 配主视觉或视频分镜图

### GitHub

目标：强化技术可信度。

形式：

- README 更新
- Release notes
- Project board / Roadmap
- Issues 征集 OPC 项目

## 转化路径

### 路径 1：OPC 创始人

社媒内容 -> OPC-Studio 官网 -> AI 拆机器 -> 项目卡 -> 提交 PitchRoom

### 路径 2：企业客户

发布公告 -> 平台定位 -> 查看项目样本 -> 私信联系 -> 推荐匹配项目

### 路径 3：生态伙伴

主视觉/长文 -> 理解 OPC 人群 -> 联系合作 -> 工具联名/资源支持

## 指标

首发 7 天建议跟踪：

- 官网访问量
- AI 拆机器完成次数
- 项目提交数
- 私信咨询数
- 社媒收藏/转发数
- 企业客户或生态合作线索数

## 发布后复盘问题

1. 哪个标题最能引发转发？
2. 用户更关心“被看见”还是“获得客户”？
3. AI 拆机器的完成率如何？
4. 提交项目的人是否符合目标 OPC 画像？
5. 是否出现企业客户或生态伙伴线索？
